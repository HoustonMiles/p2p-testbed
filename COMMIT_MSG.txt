Mesh step 4b-2: mesh trials, the worst case (everyone at once)

The runner can now run and record whole meshes, as it did pairs.

- mesh trial type (p2prunner/mesh.py): punch on every peer of the
  configuration at the same moment, in one room (the trial seed), with the
  flags in [params] args. In direct mode, peers without a key in ./keys get
  one first. Testbed.parallel(all_at_once=True) lifts the 32-at-once cap,
  since a mesh needs every peer running together.
- Trial row: pairs, pairs_usable, pairs_hop / _punch / _none / _error,
  pairs_as_predicted, time_to_usable_ms and time_to_full_mesh_ms (from the
  first peer's start until the last usable pair was ready at both ends).
- links.jsonl: one row per link end, punch's columns plus peer, member,
  the pair's outcome and predicted outcome, and each end's expected NAT
  behaviour. Written before the trial's own line; --resume drops the links
  of a trial that was interrupted in between.
- p2prunner/nat.py: the NAT expectations (moved from trials.py) and the
  RFC 4787 prediction for a pair: punch fails when one side's mapping is
  port-dependent and the other filters by port; hopping also needs both
  mappings endpoint-independent.
- punch: new column start_unix_ms, which puts every member's *_ms columns
  on one timeline.
- p2prunner mesh RUN: per configuration, ok, pairs usable, share as
  predicted, share of full meshes, time until ready.
- experiments/mesh_scale.toml: 2, 4, 8 and 16 peers, realistic (all
  port-restricted) and mixed NATs, coast profile.
- The trial registry moved to cli.py; trials.fill() is shared by the
  command and mesh trials.

Sandbox run (no netem, 2 runs per configuration): all 1,240 link ends did
as RFC 4787 predicts; realistic meshes completed at every size, time to
full mesh about 0.2 / 0.6 / 1.3 s at 4 / 8 / 16 peers; mixed meshes came up
exactly as far as the NATs allow (66 of 120 pairs at 16 peers).

Tests: the prediction against the measured pair results (punch_matrix,
Experiment A), the mesh trial on fake peers (one room, all at once, keys,
outcomes, columns, link rows), links.jsonl and its resume clean-up, the
mesh report. All 120 existing config IDs unchanged.
